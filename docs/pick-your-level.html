The Poor Man's Agentic Workflow

Which level am I?

Four places to stand, and every one of them is a fine place to stop. Click a level to see what it actually involves — what you need, what it costs you, and the catch nobody should discover later.

Level 0

So what is the cheap agent?

It is not an API key, and it is not a special product. It is simply a second coding agent — one that can read your repo, run commands, and edit files — running on a plan that charges less per token than your good one. Any agent that can read your repo qualifies. The workflow never names a vendor.

Form one · inside an editor

You open the agent and paste the one-line handoff yourself. This is what Level 2 looks like, and it is all you need there.

Form two · a headless CLI

The same agent as a terminal command, scriptable and able to run unattended. Level 3 requires this form — the reviewer has to drive the builder programmatically, and it cannot type into a window.

The worked example everything here was measured on is Cursor Pro at $20/mo. Its agent runs both ways: in the editor, and as cursor-agent in a terminal with a non-interactive mode built for scripts and CI. That second form is what makes Level 3 possible at all.

The part people get wrong

You are not buying prepaid API credits. Cursor Pro is a subscription with usage included — as of Aug 2026, $20/mo carrying $20 of third-party model usage plus its own models. A CLI API key exists, but it is for authenticating automation, not a separate meter you top up.

Why that distinction matters

The whole $40/mo claim depends on the second seat being a flat subscription. If it were metered API billing, the number would not be $40 — it would be however much you used. Exceed the included allowance and it continues at pay-as-you-go rates, which is precisely where "the $40 can creep" comes from.
