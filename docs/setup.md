# Setup - moved

**The install now lives in
[`skills/relay-setup/SKILL.md`](../skills/relay-setup/SKILL.md).**

This page used to be the read-it-yourself version of the install: seats,
accounts, and the one-time ritual per level. It described five levels and
the `templates/` layout, and the workflow now has four levels and no
`templates/` flow, so it could only have misled you.

The stub stays because the path was public for months. The full history is
in git.
